# FOCAL. — Trust Before You Connect.

> **The trusted digital layer between businesses.**

**FOCAL.** is a 24-hour hackathon project providing company identity verification, domain typosquatting detection, risk signal auditing, and Soulbound ERC-721 blockchain verification.

---

## 🎨 Visual Identity & Design System

- **Background Palette**: Pitch Black (`#050505`), Dark Surface (`#0D0D0D`), Elevated Card (`#121212`).
- **Primary Accent**: Neon Yellow (`#DFFF00`).
- **Secondary Accent**: Bright Green (`#39FF88`).
- **Risk Colors**: Verified (`#39FF88`), Warning (`#DFFF00`), High Risk (`#FF3B30`).
- **Typography**: Space Grotesk, Sora, Inter.
- **Aesthetic**: Bold tech editorial + cybersecurity intelligence + living business network.

---

## 🚀 Key Features

1. **Verification Scanner Terminal**: Interactive multi-stage cyber scanner sequence analyzing corporate identity, domain creation age, DNSSEC/MX records, risk signals, and rolling numerical Trust Score.
2. **Domain Typosquatting Character Diff**: Side-by-side domain comparison highlighting mutated lookalike characters (e.g., `company.com` vs `companny.com`) with automated alert banners.
3. **Living Trust Network View**: Interactive canvas node network (`COMPANY A ➔ FOCAL. TRUST LAYER ➔ COMPANY B`) with traveling data packet animation.
4. **Blockchain On-Chain Verification**: Ethers.js integration for inspecting soulbound NFT badges and wallet proofs on Polygon.
5. **Trusted B2B Connection Workspace**: Mediator protocol allowing verified businesses to establish monitored B2B communication channels.
6. **Risk & Scam Reporting**: Public reporting page for impersonation, fake internships, and phishing attempts with category selectors and proof links.
7. **Admin Control Dashboard**: Real-time activity feed, company entity reviews (Approve, Reject, Revoke), report review modal, and risk monitoring radar.

## 🛠️ Tech Stack

- **Frontend**: React 18, Vite, Tailwind CSS v3
- **Icons & Motion**: Lucide React, Framer Motion, Canvas API
- **Web3 / Blockchain**: Ethers.js v6 (Polygon Mainnet RPC)
- **HTTP Client**: Axios
